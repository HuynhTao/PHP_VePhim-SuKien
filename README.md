# Website đặt vé phim / sự kiện — M1 + M3

Laravel 12 · PHP 8.2+ · MySQL/MariaDB · Blade + CSS.

Bản này giữ nền tảng M1 và bổ sung module M3 của Văn Thành: rạp, phòng, sơ đồ ghế, suất chiếu và chống trùng lịch.

**Bắt đầu tại [HUONG-DAN-M3.md](docs/HUONG-DAN-M3.md).** Tài liệu có hướng dẫn giữ database hiện tại, cài mới trên XAMPP, tài khoản demo, danh sách file thay đổi, quy tắc tích hợp M4, kịch bản demo và kiểm thử.

Không cần Vite/Node để chạy các giao diện hiện có. Không kèm thư mục vendor, .env, database thực, log hoặc node_modules; cài thư viện bằng `composer install`.
